# Literature-reviewed release 0.3.0

The previous efficient experiment and its source-hashed code are preserved.
This release adds a 25-source narrative review, verified in-text references,
BibTeX, a source/version ledger, five exact mathematical witnesses, six citation
checks and a revised manuscript. It does not add GPU measurements or adapters.

Important corrections are explicit: internal versus equivalent external evidence
canonicalization has the same scoring guarantee; raw-source embedding first
does not strengthen it; output invariance is not whole-model name erasure;
quantized MLX LoRA is not a faithful QLoRA reproduction; and the close retrieval
paper by Wilson and Caliskan is cited with its 2026 erratum.

The 63-test CPU suite contains the inherited 52 and 11 new claim/citation tests.
Its additional checks do not prove academic novelty, source truth or real-world
fairness. Peer review, independent replication and real annotation/utility
studies remain outstanding.
