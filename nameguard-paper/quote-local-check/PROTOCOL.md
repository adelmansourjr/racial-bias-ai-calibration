# Testing a quote-local check at a fixed review budget

This protocol is locked before evaluating the new methods. It is a retrospective analysis of the original NameGuard Qwen archive. The human-annotated SQuAD 2.0 examples and archived scores were used in earlier work. New features and fits are evaluated using the original article-disjoint development, holdout and reserve splits. The task asks whether a proposed span answers a question about its supplied passage. Every candidate span occurs verbatim, including the plausible decoys for impossible questions.

## Acquisition and baselines

Use all 144 admitted development rows (72 same-paragraph positive/decoy pairs) for every fit, all 312 original holdout rows (156 pairs) for the primary evaluation, and all 320 reserve rows (160 pairs) for a second test. Assert unique case IDs, disjoint article sets across splits, preserved same-paragraph pairs and frozen file digests. Labels never enter a test policy. Every top-capacity policy receives the same fixed quota on each article, defined as floor(20% of its cases). Score ties use ascending public case ID. This is a batch ranking evaluation, not an independently calibrated confirmation threshold.

The one-call score is the signed A/B logit gap from the first archived Qwen prompt. The two-call reference is the mean signed gap across both orders. A training-fitted dual logistic head on the two scores and absolute disagreement is an additional reference. The quote-local method adds a small linear head to the one-call score using full-passage lexical diagnostics, question/answer nuisance features and two equal-size windows. The experimental window takes the nearest 12 lexical tokens to each side of the supplied span, shifting inward at passage ends to maintain its length, and excludes all overlapping span tokens. The other window excludes the span, uses the same number of lexical tokens and is as far as possible from it. Ties go to the earliest remaining window. Where a passage is too short to provide both disjoint views, use the largest length admitting disjoint local and distant views; both lengths remain identical. Window size is measured in lexical tokens, not model tokenisation. The full-passage diagnostics explicitly use all remaining passage tokens after deleting the candidate span.

The primary comparison uses **one-call + full passage + target window** against **one-call + full passage + distant window**. Every fit uses the common input nuisance features, the same optimisation and the same two window feature sets, choosing only which four features enter the model. Include **one-call + full passage** and **full passage + target window without Qwen**. These controls isolate the increment over unanchored or input-only overlap. Results do not estimate deployed latency. The local methods use one archived Qwen score rather than two model calls and cheap features computed from evidence the scorer has already seen.

## Endpoints and gates

Primary outcome is reduction in unsupported confirmations relative to all accepted cases on the original holdout at the matched nominal 20% capacity. Require a reduction of at least 3 percentage points versus the equal-token distant-window control and a positive 95% paired article bootstrap lower bound (4,999 draws, seed 43571). Require the reserve point estimate to be positive for a cross-cohort claim. The call-reduction comparison reports noninferiority to the stronger of the two-call method by upper bound on added unsupported confirmations (2 percentage points, prespecified comparison against dual mean). Do not call it noninferior if this interval misses the bound. Report raw counts, per-article contrasts, Brier score and matched-pair ranking accuracy. Every positive/decoy pair is used only for evaluation. Report nominal 10%, 30% and 40% capacity as secondary checks, with no gate based on those rates. The estimated intervals are conditional on the finite public articles and their construction.
