# Exact two-sentence evidence selection on SciFact

This protocol fixes the scoring, comparators and outcomes before inspecting scores or labels in the official SciFact development file for this experiment. The public archive was already used by a different project for title-to-abstract routing. This experiment uses no fitted labels, no model inference, and a different unit and endpoint. It is independent of the earlier NameGuard SQuAD experiment.

## Task and split

Use the official SciFact release archive, SHA-256 11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be. Process `claims_dev.jsonl` and `corpus.jsonl` only. Include all claim/abstract pairs for which SciFact supplies at least one valid nonempty annotated sentence rationale. The experiment is conditional on receiving an evidence-containing abstract. Include all its sentences as candidates. Fix the budget to the top two sentences per claim/abstract or the full abstract if shorter. Gold sentence indices participate only in the evaluation. Report any inclusion failures.

## Score and efficient procedures

- Tokenize lowercased Unicode alphanumeric runs, removing a fixed short list of function words and preserving negation and duplicates. Use the entire unlabelled corpus for sentence-frequency IDF. Quantize Robertson-positive IDF to positive integer weights at scale 100.
- Compute sentence BM25 for each candidate with k1=1.2 and b=0.75, using average corpus sentence length and the quantized IDF. Normalize by the query's distinct-term saturation bound and scale to 1,000. Compute an order-sensitive score using exact IDF-weighted longest common subsequence between the retained claim and sentence tokens. Divide by total claim token weight and scale to 1,000. Floor both scaled components. Final ranking uses seven times BM25 plus three times sequence score, descending, then earlier sentence index.
- Compare (1) exhaustive scoring, (2) exact weighted-bag upper bound using counts, and (3) exact ordered-pair upper bound, taking the minimum of the bag bound and two offset partitions grouping adjacent claim tokens. For a group containing two tokens, credit both if they can occur in order in the candidate, otherwise credit the heaviest individual token that occurs. Position maps establish feasibility with first and last occurrence. Combine weights across disjoint groups within each partition, including any unpaired ends.
- Both exact pruners process candidates by deterministic upper-bound key and stop when no unevaluated candidate can displace the second-ranked sentence. Use the same lexical calculation, full alignment and tie breaking across all methods. A strong approximate baseline uses BM25 to select exactly as many candidates for alignment as the ordered bound used on the same case, then returns the exact hybrid top two within that subset. It receives the number of alignments as an oracle operating budget. Also report plain BM25 at the same two-sentence read budget.
- Independently verify both bounds against weighted exact alignment on 500 fixed-seed random sequence pairs including duplicate tokens, then compare every top-two sequence against exhaustive on SciFact, including sentence order. Preserve the two-sentence budget in all arms.

## Outcomes

Primary evidence is exact agreement on every pair plus at least a 25% reduction in total dynamic-programming alignment cell updates versus exhaustive and at least a 10% reduction versus the weighted-bag pruner. If one reduction misses its threshold, report it as a separate claim. Report alignment counts and realized dynamic-programming cells separately. BM25, tokenization and bound construction also cost computation, so cell savings alone do not imply a wall-clock speedup. Report separate whole-selection process CPU timings in an independent benchmark, including per-case bounds and lexical scoring with shared preprocessing excluded.

Report the fraction of pairs for which the returned sentences include at least one gold rationale sentence and the fraction containing an entire annotated evidence set. Report the comparison with plain BM25 and the matched-alignment approximate method. Estimate a paired 95% interval for changes in complete-rationale rate using 4,999 bootstrap draws over connected components linked by shared claim or shared gold evidence document, fixed seed 79921. Report descriptive results for support and refute separately. Limit inference to these SciFact development cases, gold-abstract access and the fixed lexical scorer. The experiment measures evidence selection and computation, not verification accuracy, factuality or LLM token savings.
